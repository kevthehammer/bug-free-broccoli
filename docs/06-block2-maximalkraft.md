# Block 2 — Maximalkraft, Wochen 5–8

**Zweck dieser Datei:** Sie beschreibt Ziel, Kennzahlen und die vier Einheiten von Block 2 mit den Maximalkraft-Hauptübungen. Am Ende des Blocks steht der Re-Test nach Woche 8.

## Ziel des Blocks

- Maximalkraft
- Heavy Slow Resistance für die Patellasehne
- Rumpfsteifigkeit unter Last

## Kennzahlen

| Kennzahl | Block 2 |
| --- | --- |
| Intensität | 80–88 % |
| Wdh | 3–6 |
| RIR | 1–2 |
| Sätze/Hauptübung | Back Squat 5 × 4 (T1), Trap Bar Deadlift 5 × 3 (T3) |
| Pause | 2–3 min an Hauptübungen |
| Sprungkontakte | 80 / 100 / 120 / 60 (Wochen 5–8, siehe [docs/03-periodisierung.md](03-periodisierung.md)) |

## Wochenverlauf

| Woche | Anpassung |
| --- | --- |
| W5 | Einstieg bei 80 % |
| W6 | 85 % |
| W7 | 88 % oder gleiche Last mit einer Wdh mehr |

## Abbruch- und Anpassungskriterien

- Knie: Schmerzampel aus [docs/11-prehab-knie.md](11-prehab-knie.md) gilt unverändert.
- Schulter: Schmerzampel aus [docs/12-prehab-schulter.md](12-prehab-schulter.md) gilt unverändert.
- Technikverlust vor Erreichen der Zielwiederholungen: Satz beenden, wie in [docs/05-block1-grundlage.md](05-block1-grundlage.md).
