# Progression und Autoregulation

**Zweck dieser Datei:** Sie legt fest, wie die Last von Einheit zu Einheit gesteigert wird und wie der Trainingsplan an den täglichen Zustand angepasst wird. Die Readiness-Werte, die Einheitenvarianten und die Abbruchregeln gelten für alle Blöcke.

## Zwei Progressionsmodelle

**Doppelprogression (Block 1):** Zuerst wird die Wiederholungszahl innerhalb des vorgegebenen Korridors nach oben gesteigert. Erst wenn die obere Grenze in allen Sätzen erreicht ist, wird die Last erhöht.

**Prozentbasierte Progression (Block 2–4):** Die Last wird aus dem getesteten 1RM abgeleitet. Das 1RM stammt aus der Testbatterie in [docs/02-testbatterie.md](02-testbatterie.md), Schätzung nach Epley aus dem 3RM.

## Zielkorridore

| Block | RIR | Progression pro Woche |
| --- | --- | --- |
| 1 | 3–4 | +2,5–5 % oder +1 Wdh pro Satz |
| 2 | 1–2 | +2,5 % oder nach Prozentplan |
| 3 | 2–3 an Kraftübungen, maximale Absicht an Sprüngen | Last konstant, Geschwindigkeit steigern |
| 4 | 2–3 | Last leicht hoch, Volumen runter |

## Täglicher Readiness-Check

| Frage | Skala |
| --- | --- |
| Schlafdauer und -qualität | 1–5 |
| Muskelkater | 1–5 |
| Motivation | 1–5 |
| Knieschmerz morgens | 0–10 |
| Schulterschmerz morgens | 0–10 |

Auswertung: Summe der ersten drei Werte (Schlaf, Muskelkater, Motivation).

## Drei Varianten jeder Einheit

| Variante | Auslöser | Anpassung |
| --- | --- | --- |
| A Volle Einheit | Readiness-Summe 11–15, kein relevanter Schmerz | wie geplant |
| B Reduziert | Readiness-Summe 7–10 | Hauptübung behalten, Arbeitssätze minus ein Drittel, Assistenzübungen halbieren, Plyometrie halbieren |
| C Minimal | Readiness-Summe unter 7, oder Schmerz in der gelben Ampel | nur Prehab, Mobilität und ein technischer Satz der Hauptübung bei 60 % |

## Harte Abbruchregeln

1. Sprunghöhe im Aufwärmen mehr als 10 % unter Referenz: Plyometrie-Teil streichen.
2. Technikverlust bei der Hauptübung: Satz beenden, Last reduzieren.
3. Rote Ampel Knie oder Schulter: entsprechendes Protokoll schlägt den Trainingsplan.
4. Zwei Variante-C-Tage in Folge: eine zusätzliche Entlastungswoche einschieben.

## Wenn Wochen ausfallen

| Ausfall | Wiedereinstieg |
| --- | --- |
| bis 7 Tage | dort weitermachen, Last minus 5 % |
| 8–14 Tage | letzte Belastungswoche wiederholen, Sprungvolumen auf 60 % |
| über 14 Tage | zurück an den Anfang des aktuellen Blocks, Sprungvolumen auf 50 % |
| über 6 Wochen | Programm bei Block 1 neu starten, Testbatterie wiederholen |
