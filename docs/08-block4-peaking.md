# Block 4 — Peaking, Wochen 13–16

**Zweck dieser Datei:** Sie beschreibt Ziel, Kennzahlen und die vier Einheiten von Block 4 mit niedrigem Volumen und hoher Sprungintensität. Der Block endet mit Taper und Re-Test.

## Ziel des Blocks

- Maximale Sprungkraftausprägung bei niedrigem Volumen
- Taper
- Re-Test

## Kennzahlen

| Kennzahl | Block 4 |
| --- | --- |
| Intensität | 85–92 % |
| Wdh | 1–3 |
| RIR | 2–3 |
| Sätze/Hauptübung | Back Squat 3 × 2 (T1) |
| Pause | 3 min |
| Sprungkontakte | 120 / 100 / 80 / 40 (Wochen 13–16, siehe [docs/03-periodisierung.md](03-periodisierung.md)) |

Es gilt ein niedriges Arbeitsvolumen mit nur 2–3 Arbeitssätzen pro Hauptübung. Die Plyometrie ist maximal intensiv, aber im Umfang niedrig.

## Qualitätsregel

Jede Sprungwiederholung, die spürbar unter der besten des Tages liegt, beendet die Übung.

## Freigabe für Depth Jumps

Depth Jumps werden nur durchgeführt, wenn das Knie über die letzten 4 Wochen beschwerdefrei war. Andernfalls bleibt der Depth Drop mit Landung halten im Programm.

## Wochenverlauf

| Woche | Anpassung |
| --- | --- |
| W13 | höchste Intensität |
| W14 | Intensität halten, Volumen −20 % |
| W15 | Volumen −40 %, nur Qualitätssprünge |
| W16 | Taper (Volumen −60 %, keine Plyometrie über 40 Kontakte) und Re-Test am Ende der Woche (siehe [docs/02-testbatterie.md](02-testbatterie.md)) |

## Abbruch- und Anpassungskriterien

- Qualitätsregel oben: Sprungwiederholungen unter der besten des Tages beenden die Übung.
- Depth Jumps nur mit Freigabe oben, sonst Depth Drop mit Landung halten.
- Knie: Schmerzampel aus [docs/11-prehab-knie.md](11-prehab-knie.md). Schulter: Schmerzampel aus [docs/12-prehab-schulter.md](12-prehab-schulter.md).
