# Block 3 — Schnellkraft, Wochen 9–12

**Zweck dieser Datei:** Sie beschreibt Ziel, Kennzahlen und die vier Einheiten von Block 3. Im Mittelpunkt stehen die Umwandlung der Maximalkraft in Sprungkraft und die Kontrastmethode.

## Ziel des Blocks

- Umwandlung der Maximalkraft in Sprungkraft
- Reaktivkraft
- Kontrastmethode

## Kennzahlen

| Kennzahl | Block 3 |
| --- | --- |
| Intensität | 80–90 % + 30–50 % (explosiv) |
| Wdh | 2–5 |
| RIR | 2–3 an Kraftübungen, maximale Absicht an Sprüngen |
| Sätze/Hauptübung | Back Squat 4 × 3 (T1), Trap Bar Deadlift 3 × 3 (T1), Hip Thrust 4 × 4 (T3) |
| Pause | 90–120 s nach der schweren Übung im Kontrastsatz |
| Sprungkontakte | 100 / 120 / 140 / 70 (Wochen 9–12, siehe [docs/03-periodisierung.md](03-periodisierung.md)) |

## Kontrastmethode erklärt

Eine schwere Übung mit 2–4 Wiederholungen bei 80–90 % wird gefolgt von 90–120 s Pause und dann von einer plyometrischen Übung mit maximaler Bewegungsabsicht. Die schwere Übung aktiviert das Nervensystem vor (Voraktivierung), und die anschließende Sprungübung wird mit hoher neuronaler Ansteuerung ausgeführt.

Warnung: Bei Ermüdung verschwindet dieser Effekt. Der Kontrastsatz wird dann abgebrochen.

## Freigabe-Kriterium

Die Plyometrie wird nur gesteigert, wenn der Knieschmerz in Block 2 durchgehend bei maximal 3/10 lag und am Folgetag auf Ausgangsniveau zurückging. Andernfalls fährt Block 3 mit dem Plyometrie-Umfang von Block 2.
