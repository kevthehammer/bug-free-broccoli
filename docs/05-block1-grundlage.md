# Block 1 — Grundlage, Wochen 1–4

**Zweck dieser Datei:** Sie beschreibt Ziel, Kennzahlen und die vier Einheiten von Block 1 mit Übungen, Intensitäten und Pausen. Der Block legt die Grundlage für Sehnenkonditionierung und saubere Technik.

## Ziel des Blocks

- Work Capacity
- Sehnenkonditionierung über Isometrie
- Technik unter Ermüdung
- Skapula-Kontrolle
- Sprunggelenksteifigkeit

## Kennzahlen

| Kennzahl | Block 1 |
| --- | --- |
| Intensität | 65–75 % |
| Wdh | 6–10 |
| RIR | 3–4 |
| Sätze/Hauptübung | Back Squat 4 × 8 (T1), Trap Bar Deadlift 4 × 6 (T3) |
| Pause | 90–120 s |
| Sprungkontakte | 60 / 80 / 100 / 50 (Wochen 1–4, siehe [docs/03-periodisierung.md](03-periodisierung.md)) |

## Wochenverlauf

| Woche | Anpassung |
| --- | --- |
| W1 | Einführung, Last konservativ wählen |
| W2 | gleiches Volumen, Last +2,5–5 % |
| W3 | höchstes Volumen, Last +2,5–5 % |
| W4 | Entlastung: Volumen −40 %, Intensität −10 %, Plyo max. 50 Kontakte, Isometrie bleibt vollständig |

## Abbruch- und Anpassungskriterien

- Knieschmerz über 3/10 während der Belastung oder erhöhte Morgensteifigkeit: Ampel aus [docs/11-prehab-knie.md](11-prehab-knie.md).
- Schulterschmerz im schmerzhaften Bogen: Ampel aus [docs/12-prehab-schulter.md](12-prehab-schulter.md).
- Technikverlust vor Erreichen der Zielwiederholungen: Satz beenden.
